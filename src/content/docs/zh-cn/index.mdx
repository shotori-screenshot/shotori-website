## 功能亮点

<CardGrid stagger>
	<Card title="Wayland 原生" icon="mdi:monitor">
		基于 <code>wlr-screencopy</code> 与 layer-shell 构建，在 niri、sway、Hyprland
		等 wlroots 系合成器上如鱼得水。混合缩放、旋转输出的多显示器环境都能正确处理，选区可以跨屏。
	</Card>
	<Card title="本地 OCR" icon="mdi:text-recognition">
		文字识别在本机运行，首次使用下载约 31 MB 模型，之后任何数据都不会离开你的电脑。
	</Card>
	<Card title="长截图" icon="mdi:scroll">
		框住滚动区域，自己滚动，看着拼接结果在侧边实时预览中生长。若选区里有不随内容滚动的部分，会安全停止并保留已捕获的内容。
	</Card>
	<Card title="贴图" icon="mdi:pin">
		把选区钉成置顶浮动小窗，截图界面关闭后依然保留——可跨屏拖动、滚轮缩放。
	</Card>
	<Card title="完整标注工具" icon="mdi:draw">
		矩形、箭头、序号、画笔、荧光笔、马赛克和文字——画完可继续编辑与撤销。
	</Card>
</CardGrid>

## 状态

Shotori 处于早期开发阶段（pre-1.0）。截图、标注、复制、保存、OCR、贴图、
长截图这些核心流程已可日常使用，但命令行参数、键位与主题格式尚未稳定。
目前只在 niri 和 Hyprland 上测试过，其他 Wayland
合成器欢迎大家试用并[反馈](https://github.com/shotori-screenshot/shotori/issues)结果。
